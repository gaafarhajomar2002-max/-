# التغذية الاستقلابية

> [!define] الاستقلاب
> مجموعة عمليات البناء والهدم

- الدكسترينات ← تحلل جزئي للنشاء
- البروتينات هي: سكر + NH~3~ ← حمض أميني غير أساسي من أصل سكري
- يتحول السكر في الفم عبر أنزيم الأميلاز ← دكسترينات + مالتوز ← غلوكوز + غلوكوز (جزيئتا غلوكوز)

## خواص السكريات الأحادية

1. لونها أبيض
2. مُحلّاة جميعها
3. تكون إما ألدهيد أو كيتون
4. فيها مجاميع غولية

## السكريات المركبة

| السكر | يتألف من | الرابطة |
| **مالتوز** | غلوكوز + غلوكوز | α(1-4) |
| **لاكتوز** | غالاكتوز + غلوكوز | β(1-4) |
| **سكروز** | غلوكوز + فركتوز | (1α)(2β) |

> [!note] في الدفتر كُتب اللاكتوز "غالاكتوز + لاكتوز"، وهو سهو كتابة: اللاكتوز = غالاكتوز + غلوكوز.

# يتم استقلاب السكر بطريقين

1. **لاهوائي**: يعطي طاقة قليلة = 2ATP ولكنه ينتهي بحمض اللبن، هنا يتم التحلل في السيتوبلازما بلا تدخل الميتوكوندريا.
2. **هوائي**: يتم في الميتوكوندريا بوجود O~2~ يعطي طاقة عالية = 38 ATP

# اللاهوائي يمر بثلاث مراحل

## 1. تحول الغلوكوز إلى 2 مول من غليسرالدهيد-3-فوسفات

| المتفاعلات | الأنزيم | النواتج |
| α-غلوكوز + ATP | **غلوكوكيناز** (تفاعل غير عكوس) | غلوكوز-6-فوسفات + ADP |
| غلوكوز-6-فوسفات | **فوسفوغلوكوايزوميراز** (إيزوميراز)، تفاعل باتجاهين ⇌ | فركتوز-6-فوسفات |
| فركتوز-6-فوسفات + ATP | **فوسفوفركتوكيناز** | فركتوز-1,6-ثنائي الفوسفات |
| فركتوز-1,6-ثنائي الفوسفات | **الدولاز** (تنشطر إلى) | داي هيدروكسي أسيتون فوسفات + D-غليسرالدهيد-3-فوسفات |
| داي هيدروكسي أسيتون فوسفات | **إيزوميراز** | D-غليسرالدهيد-3-فوسفات |

> [!summary] المرحلة الأولى:
> غلوكوز + 2ATP ← 2 غليسرالدهيد-3-فوسفات + 2ADP

## 2. تحول غليسرالدهيد-3-فوسفات إلى بيروفات

كل 1 مول من غليسرالدهيد-3-فوسفات + H~3~PO~4~ + NAD^+^ ← 2 بيروفات + 2ATP

NAD^+^: فيتامين ذواب بالماء.

> [!check] كتب الدفتر "2 بيروفات"، بينما التفاعلات التالية في الدفتر نفسه تعطي من كل 1 مول غليسرالدهيد-3-فوسفات **1 بيروفات و2ATP** (أي 2 بيروفات من الغلوكوز الواحد). تأكد من دفترك.

| المتفاعلات | الأنزيم | النواتج |
| غليسرالدهيد-3-فوسفات + NAD + H~3~PO~4~ | **غليسرالدهيد ديهيدروجيناز** (NAD: أكسدة، H~3~PO~4~: فسفرة) | 1,3-ثنائي فوسفوغليسيرات + NADH + H^+^ |
| 1,3-ثنائي فوسفوغليسيرات + ADP | (تعطي طاقة) | 3-فوسفوغليسيرات + ATP |
| 3-فوسفوغليسيرات | | 2-فوسفوغليسيرات |
| 2-فوسفوغليسيرات | | H~2~O + فوسفوإينول بيروفات |
| فوسفوإينول بيروفات + ADP | | بيروفات + ATP |

## 3. إعادة أكسدة NADH + H^+^ إلى NAD في ظروف غير هوائية

| المتفاعلات | | النواتج |
| بيروفات + NADH + H^+^ | ← | L-حمض اللبن + NAD^+^ |

> [!exam] اختبار: ماهي كمية الطاقة الناتجة عن تحول الغلوكوز لاهوائياً؟
> الجواب: 2 حمض لبن + 2 ATP.
