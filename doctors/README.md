# ملفات نمط الدكاترة

لكل دكتور ملف `اسم-الدكتور.md` بيتحدّث بعد كل محاضرة، وفيه:
- المواد اللي بيدرّسها
- على شو بيركّز (تعاريف، مسارات، أرقام، مقارنات، حالات سريرية...)
- شكل أسئلته بالامتحان (صح وغلط، اختيار من متعدد، مقالي...)
- العبارات اللي بيقولها لما يكون الشي مهم ("انتبهوا"، "هي بتجي"...)
- ملاحظات من المحاضرات السابقة

هالمعلومات بتساعد بكتابة صندوق "نمط الدكتور" وباختيار التنبيهات والأسئلة بكل محاضرة جديدة.
