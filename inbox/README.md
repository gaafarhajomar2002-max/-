# صندوق الاستلام

حط هون تسجيلات المحاضرات كما هي، بأي اسم وبأي ترتيب، حتى لو فيها مكرر أو ملفات مش للمادة.

بعدها Claude بيعمل:
1. **فرز** (`tools/triage.py inbox/`): بيكشف المكرر (حتى لو مقصوص أو بصيغة تانية)، وبيسمع مقاطع من كل ملف ليعرف مادته، وبيرتّبهم حسب تاريخ التسجيل.
2. بيعرض عليك النتيجة لتأكدها.
3. بينقل كل تسجيل صحيح لمجلده `lectures/<المادة>/<الرقم>-<الموضوع>/` وبيفرّغه وبيعمل ملف الوورد.
