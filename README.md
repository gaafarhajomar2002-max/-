# محاضرات التغذية: تفريغ وتنسيق

هذا المشروع بيحوّل تسجيل المحاضرة (عربي، لهجة سورية) لملف **وورد** منسّق للدراسة، وفيه:

1. **غلاف** ملوّن فيه رقم المحاضرة واسم المادة والدكتور.
2. **بطاقة المحاضرة** مع **الفهرس**، وبعدها **نمط الدكتور** (على شو بيركّز وكيف بيسأل).
3. **الشرح** مقسّم لفصول، مع صور من ويكيبيديا وويكيميديا كومنز، والحشو مختصر، والنقاط اللي ما انشرحت منيح موضّحة.
4. صناديق ملوّنة داخل الشرح:
   - ★ **الدكتور شدّد على هذا**
   - ؟ **سؤال متوقّع بالامتحان** (مع الفكرة أو الجواب)
   - ✎ **توضيح إضافي**
   - ◆ **تذكّر**
   - ✓ **طريقة للحفظ**
   - ✗ **خطأ شائع**
5. **ملحق المراجعة** بآخر الملف: كل اللي شدّد عليه الدكتور وكل الأسئلة مجمّعة بمكان واحد.

الصناديق كمان بتشمل **عرّف**، **علّل**، و**مسألة محلولة** (معطيات، قانون، حل، نتيجة)، وكلها بتتجمّع بالملحق.
الصيغ الكيميائية بتطلع مضبوطة (H₂O، Ca²⁺) جوّا النص العربي.

**المواد المجهّزة** (السنة الثالثة، تغذية علاجية): علوم وتكنولوجيا الأغذية، التغذية وعلم السموم، تغذية علاجية 1،
كيمياء وتحليل الأغذية، تداخل الغذاء والدواء، كيمياء تغذوية 1 و 2، كيمياء، لغة 3. التفاصيل بملف [`courses.json`](courses.json).

مثال جاهز: [`lectures/00-sample-vitamin-d/`](lectures/00-sample-vitamin-d/)

## كيف تبعتلي المحاضرة

**الطريقة 1: ارفع الصوت هون على GitHub**
- افتح المستودع، بعدين **Add file ← Upload files**، وارفع الملف. مش ضروري تختار مجلد، أنا بنقله لمكانه.
- رفع الملفات من موقع GitHub حدّه **25 ميغا** للملف الواحد. إذا كان التسجيل أكبر:
  - إما تضغطه، مثلاً من تطبيق تسجيل بجودة "منخفضة" أو "صوت" (ساعة ونص بحدود 15–20 ميغا)،
  - أو تقسمه لأجزاء (part1, part2, ...) وأنا بدمجهم.
- بعدها قلّي "رفعت محاضرة كذا" وأنا بكمّل.

**الطريقة 2: فرّغها إنت وابعتلي النص**
- ارفع الصوت على NotebookLM (أو أي أداة تفريغ)، وانسخ التفريغ وابعتلي ياه هون بالمحادثة.
- أنا بكمّل الباقي: التنسيق والصور والأسئلة وملف الوورد.

**مفيد تذكرلي مع كل محاضرة:** اسم المادة، اسم الدكتور، رقم المحاضرة، والتاريخ.
